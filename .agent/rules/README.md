# Rules (L2)

Rules tell you HOW to build it (constraints).

## Hierarchy

P1: CRITICAL.md (Security, compliance)
P2: architecture.md (System constraints)
P3: {domain}.md (ui, api, db)
P4: preferences.md (Style conventions)
P5: Industry defaults

## Structure

```markdown
# Rule: {Domain}

## MUST

## SHOULD

## MUST NOT

## EXCEPTIONS
```
